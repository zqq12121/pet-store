## 本地开发专用接口

`POST /api/v1/demo/orders/{orderId}/pay`（兼容现有前端），别名 `/api/v1/dev/orders/{orderId}/pay`。

要求买家登录、本人未过期待付款订单，只模拟付款事实，不访问微信。仅 local/test 模式有效。正常支付能力接口不会把模拟能力冒充微信已开通。
