## 插件将执行的操作

1. 核对目标 Figma 文件标识、三页既有节点与上传照片。
2. 加载现有中文字体与颜色变量。
3. 在原有画布右侧添加可编辑的自动布局页面及可复用按钮、卡片组件。
4. 为各端首页设置原型入口，连接已经存在的目标状态。
5. 添加按钮悬停 180ms、普通页面淡入 300ms、筛选页滑入 280ms、每 5 秒切换且淡入 450ms 的双帧首页轮播。
6. 在插件面板显示生成数量、跳转数、节点 ID 和错误。

插件不读取本地文件、业务账号、剪贴板，不调用支付、短信、AI 或退款接口。manifest 设置 `networkAccess.allowedDomains = ["none"]`。只修改当前目标 Figma 文件；不会删除或改写已有基础设计。再次运行会跳过同名交付页面，补全跳转，避免重复生成。单页失败时仅移除本次未完成的该页，已经完成的页面保留。

插件提供“生成三端首页”和“生成全部页面”两个按钮。批准导入后，先生成首页检查实际 Figma 排版，再生成其余页面。原型表单、上传、付款、AI 和退款属于状态演示，不构成可用的业务功能。
