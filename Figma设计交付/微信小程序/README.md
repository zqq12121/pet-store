## 视觉与结构

屏幕为 `390 × 844`。采用奶油白、暖橙和深灰文字，宠物照片作为视觉重点；主体文字约 14px，标题约 22–25px。相关内容用自动布局组织，长内容放在滚动区域，底部按钮与四入口导航保持独立。

复用原文件的颜色、间距、圆角变量与中文字体。新增微信系统导航组件、底部导航的四种选中状态、紧凑宠物卡片组件；文本、图标与布局为可编辑图层，照片使用原文件已有图片。

顶部保留微信胶囊；底部为“首页／选宠／预约／我的”，含安全区。页面内主要操作按钮高 48px。主流程为：浏览 → 奶糖详情 → 手机号登录 → 到店预约 → 提交结果 → 预约记录；预约详情可进入到店指南。

## 业务与原型范围

沿用当前练习项目资料：茸茸星球，每天 08:00–17:00，携带身份证到店。地址标注“虚构地址，仅供练习”，档案标注“模拟资料，仅供测试”，编号使用 `DEMO-`。电话、微信、地图坐标为空，因此不设计对应操作。

线上只安排到店预约，不收款。手机号、验证码、预约、AI 回复均为原型示例。此交付属于 Figma 设计，没有开发小程序代码或接通微信授权。

原型主要围绕奶糖示例串联。其他宠物卡片当前也进入奶糖详情演示。分类、筛选的链接尚需细化；验证码、日期时间选择和聊天发送区为静态外观，不能视为已实现的交互功能。
