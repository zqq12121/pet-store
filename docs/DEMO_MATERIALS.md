预约与历史售后的完整验收、隔离测试账号及演示命令见 [简历项目演示指南](DEMO_GUIDE.md)。下方“本轮”指材料生成与导入阶段，后续验收交易只创建在隔离副本。

## 本机资料与再次生成

生成脚本是 `scripts/seed-demo-materials.py`。输出位于 `output/demo-materials/`，该目录不提交 Git：

- `茸茸星球-模拟资料包.pdf`：24 页，含 20 页个体记录、诊断样例、证据样例及两页模拟协议。
- `diagnosis-demo.png`：在本人演示订单下按 `diagnosis` 用途上传。
- `after-sale-evidence-demo.png`：在演示订单下按 `after_sale_evidence` 用途上传。
- `manifest.json`：目标宠物、文件 ID 和 SHA-256。
- `import.sql`：本次生成对应的事务导入语句，应通过脚本应用。
- `verification.json`：本次只读验证结果。

脚本在当前 macOS 使用系统 Arial Unicode 字体并嵌入 PDF，需要 Docker Compose、ReportLab、pypdf 和 `pdftoppm`。当前电脑可复制以下命令：

```sh
cd '/Users/zhangquan/Documents/ChatGPT/宠物门店电商网站'
# 只读查询示例档案并生成文件，不导入数据库。
/Users/zhangquan/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/seed-demo-materials.py
# 完整备份，再上传文件并事务导入；备份期间网站短暂停止。
/Users/zhangquan/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/seed-demo-materials.py --apply
```

脚本只处理明确带示例标记、已有照片且没有关联订单的宠物。若示例被预约或版本在生成后变化，停止导入。相同日期和个体的模拟记录与文件编号可重复生成；已有协议正文不覆盖。更换日期生成时会创建新的材料版本。

诊断、售后证据需要绑定实际演示订单并接受现有权限校验，本轮只提供可上传样例，没有创建订单或未关联的诊断记录。文件按现有 OSS 私有对象规则存储；公开证明通过应用的公开媒体接口展示。
