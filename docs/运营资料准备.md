## 1. 门店资料

请在本表或后台填写真实信息。证件原件、个人联系方式、密钥等私密材料应通过适当的私密渠道处理，不提交 Git。

| 项目 | 待填写内容 | 用途 |
| --- | --- | --- |
| 经营主体名称 | 待店主填写 | 协议主体、短信签名申请 |
| 门店展示名称 | 待店主填写 | 首页和门店页面 |
| 经营地址 | 待店主填写完整地址 | 到店导航、协议主体 |
| 地图坐标 | 待店主确认，GCJ-02 | 到店地图 |
| 对外联系电话 | 待店主填写 | 预约沟通、售后联系 |
| 对外微信 | 待店主填写 | 顾客联系 |
| 每日营业时间 | 待店主填写，例如 `每天 10:00-20:00` | 后端预约时间校验 |

## 2. 短信签名与模板申请

在阿里云短信服务申请与经营主体匹配的通知签名，并提交以下五类通知模板。
以下文案是与当前程序参数匹配的草案；最终以平台审核要求为准。
平台审核可能要求业务材料、变量限制或文案调整；审核结果出来后再核对程序参数。

| 事件 | 提交文案草案 | 根目录配置变量 |
| --- | --- | --- |
| 预约提交 | 您的到店预约已提交，预约编号${orderId}，到店时间${visitAt}。请等待门店确认。 | `PAW_SMS_APPOINTMENT_SUBMITTED_TEMPLATE` |
| 预约确认 | 您的到店预约已确认，预约编号${orderId}，到店时间${visitAt}。请按时到店。 | `PAW_SMS_APPOINTMENT_CONFIRMED_TEMPLATE` |
| 预约取消 | 您的到店预约已取消，预约编号${orderId}，原到店时间${visitAt}，取消原因${reason}。如有疑问请联系门店。 | `PAW_SMS_APPOINTMENT_CANCELLED_TEMPLATE` |
| 预约过期 | 您的到店预约已过期，预约编号${orderId}，原到店时间${visitAt}。如仍需到店，请重新预约。 | `PAW_SMS_APPOINTMENT_EXPIRED_TEMPLATE` |
| 交付完成 | 您的预约编号${orderId}已完成到店交付，预约到店时间${visitAt}。如需售后帮助，请联系门店。 | `PAW_SMS_APPOINTMENT_COMPLETED_TEMPLATE` |

短信平台按已审核签名添加签名前缀。通知只发给预约联系人，当前没有店主手机通知。
`orderId` 是系统订单 ID；`visitAt` 是预约时间，不是实际交付时间；`reason` 来自取消原因。
提交时核对变量名、实际长度和允许字符，尤其是取消原因；若模板要求改变参数，需要同步修改并测试程序。

审核通过后只在本机 `.env` 填写签名与平台返回的 `SMS_...` 模板编号。
短信专用 AccessKey ID/Secret 必须成对配置，赋予所需的短信调用权限；不要把登录验证码模板用于通知。
修改后重建对应容器配置（仅 restart 不会载入新环境变量）：

```sh
docker compose up -d --no-build --wait order-server admin-server
# 公网环境使用同一条命令时加上两个 -f：
# docker compose -f compose.yaml -f compose.production.yaml up -d --no-build --wait order-server admin-server
docker compose --profile tools run --rm readiness
```

最后用店主指定的验收手机号确认真实送达；不要把平台受理当成送达，也不要把测试交易写成真实收款。

## 3. 正式交易协议需要确认的内容

请由店主根据实际经营方式和适用要求确认下列条款，必要时请专业人士审阅。现有示例或本表不能直接当作正式协议发布。

- 销售主体、经营地址、联系和投诉渠道。
- 个体宠物信息、价格、健康及检疫材料的展示与核验范围。
- 预约只是到店安排；线上不收款。何时确认交易、线下付款方式及凭证。
- 预约取消和逾期处理，以及门店无法按约交付的处理方式。
- 到店健康检查、材料核验、交付清单和双方确认方式。
- 健康保障期间、售后受理流程、退款及费用承担；须与真实能力和系统配置一致。
- 顾客手机号、预约信息、文件的使用目的、访问范围、保存及删除规则。
- 争议处理方式、协议生效时间、版本及签署记录。

正式文本确认后，在后台创建草稿、检查内容，再发布为 `live_pet_trade` 当前版本。
发布会影响后续预约使用的协议，应由店主确认最终正文。历史签署版本保留。
