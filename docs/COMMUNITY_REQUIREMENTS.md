# 宠友社区需求 v1

更新日期：2026-10-11。

本文记录需求讨论中已确认的第一版功能与边界规则。本文为需求文档，不代表功能已经实现或通过运行验收。

## 1. 定位与入口

- 以养宠交流为主，店铺评价作为专区。
- 网站主导航新增“宠友社区”，社区内分为“养宠交流”和“店铺评价”两个板块。
- 店铺页面提供跳转到店铺评价专区的入口。
- 项目继续用于个人练习与简历展示。

## 2. 浏览与参与权限

| 操作 | 已确认的权限 |
| --- | --- |
| 浏览帖子、评价及其公开评论和回复 | 所有人，包括未登录访客 |
| 发布养宠交流帖子 | 所有登录用户，不要求消费记录 |
| 发表评论、回复评论 | 登录用户；帖子和店铺评价均开放讨论 |
| 点赞帖子、收藏帖子 | 登录用户 |
| 发表店铺评价 | 登录用户，且评价关联本人已完成交付的订单 |
| 举报公开内容 | 登录用户 |
| 修改帖子、评价 | 内容作者本人 |
| 删除帖子、评价、评论和回复 | 内容作者本人 |
| 隐藏违规内容、处理举报 | 店铺管理员 |
| 新增、修改和停用恶意词条 | 店铺管理员 |
| 以店铺身份回复评价 | 店铺管理员，展示“店铺回复”标识 |

权限需要在服务端验证，不能只通过隐藏前端按钮控制。用户不能借用其他用户的订单评价，也不能修改、删除其他用户的内容。

## 3. 养宠交流

### 帖子内容

- 包含标题、正文和可选图片。
- 发帖时从三个固定分类中选择一个：养宠心得、晒宠日常、求助问答。
- 支持文字和多张图片，第一版不包含视频上传。
- 每帖最多上传 9 张图片，每张不超过 5 MB，支持 JPG、PNG、WebP。

### 查找与互动

- 帖子默认按发布时间从新到旧排列。
- 支持按三个固定分类筛选。
- 支持对标题和正文进行关键词搜索。
- 登录用户可以评论、回复、点赞和收藏帖子。
- 用户可以修改、删除自己的帖子。
- 评论和回复只能由本人删除，不支持本人编辑。

## 4. 店铺评价

### 评价资格与内容

- 评价关联本人已完成交付的订单，仅预约、确认预约或尚未完成交付不满足评价资格。
- 每个已完成交付的订单只能发表一次评价；再次消费后，可以针对另一个已完成交付的订单发表评价。
- 评价包含 1～5 星总体评分、文字和可选图片。
- 每条评价最多上传 9 张图片，每张不超过 5 MB，支持 JPG、PNG、WebP。
- 所有人都可以浏览公开评价。

### 修改、删除与讨论

- 作者可以修改、删除自己的评价。
- 修改评价不会产生第二条评价，仍关联原订单。
- 删除后，该订单仍算已评价，不能重新发表评价。
- 删除前明确提示：删除后该订单不能再次评价。
- 所有登录用户都可以在评价下发表评论和回复。
- 管理员以店铺身份回复时，显示“店铺回复”标识。
- 评价下的评论和回复支持本人删除，不支持本人编辑。

实现时必须保留订单已评价的记录，避免删除后恢复评价资格；并发或重复提交也不能让同一订单产生多条评价。

## 5. 评论与回复展示

- 帖子和店铺评价采用同一套两层展示规则。
- 第一层展示主评论；第二层集中展示该主评论下面的回复。
- 第二层回复标明回复对象。
- 用户可以继续回复第二层中的内容，后续对话仍展示在第二层，不继续增加缩进层级。
- 作者删除自己的主评论后，该主评论及其下方全部回复不再展示。
- 作者删除自己的单条回复后，其他回复继续保留；涉及被删除回复的引用显示“原回复已删除”。

## 6. 发布检查与内容管理

- 帖子、评价、评论和回复在发布前检查恶意词汇，店铺回复也执行相同规则。
- 命中恶意词汇时阻止发布，提示用户修改；不采用替换成星号后发布的方式。
- 帖子和评价修改时重新检查恶意词汇，未通过时不能保存本次修改。
- 通过检查的内容立即公开展示，无需管理员逐条预审。
- 登录用户可以举报，管理员可以处理举报并隐藏违规内容。
- 被隐藏或删除的内容不再作为公开内容展示。
- 管理员可以在后台维护恶意词库，支持新增、修改和停用词条，便于调整拦截范围与误拦截。

## 7. 站内通知

- 自己的帖子收到评论时，产生站内通知。
- 自己的店铺评价收到评论时，产生站内通知。
- 自己的评论收到回复时，产生站内通知。
- 通知支持未读标记和点击跳转到对应内容。
- 第一版选择的是评论和回复通知，不包含点赞通知。

## 8. 文字长度限制

长度按字符计算，中文和英文字母都各算一个字符。

| 内容 | 最大字符数 |
| --- | --- |
| 帖子标题 | 80 |
| 帖子正文 | 5000 |
| 店铺评价正文 | 1000 |
| 评论和回复，包括店铺回复 | 500 |

发布和修改时均检查适用的长度限制；超过上限时阻止提交并提示对应上限。前端与服务端采用一致的计数规则。

## 9. 实现后的验收场景

以下是后续开发验收标准，本轮尚未执行功能测试。

| 场景 | 预期结果 |
| --- | --- |
| 未登录访问两个板块及公开内容详情 | 可以浏览 |
| 未登录尝试发帖、评论、回复、点赞、收藏或举报 | 要求登录；服务端拒绝未登录操作 |
| 登录用户没有消费记录 | 可以发帖和讨论，但不能发表店铺评价 |
| 使用未完成交付的订单或其他用户的订单评价 | 服务端拒绝 |
| 针对本人已完成交付的订单发表评价 | 成功发布，并关联对应订单 |
| 同一订单重复评价，包括并发提交 | 最多一条评价成功 |
| 删除评价后再次用原订单评价 | 拒绝；删除前已展示后果提示 |
| 上传超过 9 张图片、单张超限或不支持的格式 | 拒绝超出图片规则的提交 |
| 发布或修改内容时超过适用文字上限 | 拒绝提交并提示上限；恰好达到上限时不因长度被拒绝 |
| 帖子选择分类、搜索标题或正文 | 返回符合条件的内容；默认按最新发布排序 |
| 连续回复第二层内容 | 仍显示在第二层，并标明回复对象 |
| 作者删除自己的主评论 | 主评论及其下方全部回复不再展示 |
| 作者删除自己的单条回复 | 其他回复保留，涉及该回复的引用显示“原回复已删除” |
| 发布内容或修改帖子、评价时命中恶意词汇 | 阻止提交并提示修改 |
| 内容通过恶意词检查 | 立即展示，无需人工预审 |
| 用户尝试修改或删除他人内容 | 服务端拒绝 |
| 用户操作自己的帖子、评价、评论和回复 | 修改、删除范围符合已确认规则 |
| 管理员以店铺身份回复评价 | 显示“店铺回复”标识 |
| 登录用户举报，管理员隐藏违规内容 | 举报可处理，隐藏后的内容不再公开展示 |
| 管理员维护恶意词库 | 可以新增、修改和停用词条；普通用户不能维护词库 |
| 帖子或评价收到评论，评论收到回复 | 对应作者收到站内通知，支持未读标记和跳转 |

后续如果使用模拟社区内容进行演示，应明确标注为模拟资料，不能当作真实用户评价或真实消费记录展示。
